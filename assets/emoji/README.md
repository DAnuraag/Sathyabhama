Twemoji graphics (the emoji artwork Twitter/X published), CC BY 4.0: https://github.com/jdecked/twemoji

Files are copied unchanged from the npm package `@twemoji/svg` (file name = Unicode code point).
Credit is required: it is in the site footer, keep it.

Used for the kisses/hearts thrown from the letter.
Any Twemoji file works: drop it here and use its code point (e.g. `1f60d`) to the `THROWN` list in `js/effects.js`.
