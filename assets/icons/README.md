# Icons

From **Pixelarticons** by Gerrit Halfmann, MIT licence (`LICENSE.txt`): https://github.com/halfmage/pixelarticons
Files are copied unchanged from the npm package `pixelarticons` (`svg/` folder).

To swap an icon: drop another `.svg` in this folder (a `fill="currentColor"` one picks up the card colour) and use its
file name (without `.svg`) as `icon:` in `config.js`.
