# Optional extras (transparent PNG)

Drop any of these in this folder. The site checks whether each file really exists and only then places it in the scene. Nothing is drawn as a fake substitute.

| File | Where it appears | Depth |
|---|---|---|
| `couple-silhouette.png` | Stands on the ground layer, fades in for the night finale | 0.92 |
| `birds.png` | Replaces the built-in SVG birds that cross the sky (one bird per image) | 0.52 |
| `heart-balloon.png` | Floats gently at mid depth | 0.80 |

Where to find them (check the licence and credit the author if required):
Pixabay, SVG Repo, or Freepik. Search "couple silhouette sunset", "birds silhouette" or "heart balloon", and choose a transparent PNG.
Tip: couple and birds should be dark silhouettes. The couple is darkened automatically to match the forest.
